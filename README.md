# Living Universe

*A personal creative hobby exploring autonomous civilizations and an evolving fantasy universe.*

Living Universe is an open-source, research-inspired creative project to explore a persistent shared world where autonomous inhabitants develop cultures, knowledge, economies, technologies and extraordinary abilities over long periods of time.

**Status: design and architecture phase.** There is no playable simulation yet. This repository documents the full intended vision without claiming that planned capabilities already exist.

## The vision

One continuous, server-authoritative world with five culturally distinct starting regions—magic, cultivation and immortality, science, primal, and inborn superpowers—surrounding a central meeting island. Mana, qi, ordinary matter and other phenomena coexist under common rules. Characters may learn across traditions. Long-lived beings can develop understanding over millennia. Their actions can change landscapes, institutions and history. An observer interface and a 2D multiplayer RPG will access the same simulation.

Separate experimental copies allow reproducible research without rewriting the shared world's history.
