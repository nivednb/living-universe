# Roadmap

These are capability milestones, not separate incompatible world prototypes.

1. **Specification and decisions** — define complete world model, invariants, event schema, agent identity, fields and knowledge provenance.
2. **Reuse audit** — inspect code and artwork licenses, integration feasibility, maintenance and performance.
3. **Authoritative kernel** — deterministic scheduling, persistent state, history, experiments and tests.
4. **World mechanics** — perception, cross-tradition learning, discoveries, breakthroughs, damage and restoration.
5. **Civilizations** — institutions, economy, migration, inheritance, population and long-run scaling benchmarks.
6. **Clients** — observer/research tools, 2D exploration, multiplayer and intervention.
7. **Operations** — deployment, cost measurements, backups, documentation and contributions.

**Current status:** a tested Python reference kernel implements scheduling,
travel/research, historical knowledge, validated persistence and renderer-neutral
observer/character views. Production scaling, autonomous civilizations, physical
spatial fields and playable clients remain open. See the [view contract](architecture/view-contract.md)
for the boundary between simulation authority and future 2D/3D presentation.
