# ADR-0003: Original source-informed histories

**Status:** Accepted (2026-11-04)

Use global historical, mythological, folkloric and fictional research to create an original initial historical graph for the five cultures. Fiction is a source of inspiration, not a database of reusable protected characters, plots or dialogue. Keep evidence, belief, myth, simulation ground truth and secret knowledge separate. Track provenance and licensing; see [source policy](../research/source-and-copyright-policy.md) and [historical seeding](../world/historical-seeding.md).

The simulation continues autonomously from the seeded world; no predetermined outcomes.
