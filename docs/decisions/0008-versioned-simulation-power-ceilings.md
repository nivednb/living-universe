# ADR-0008: Versioned simulation power ceilings

**Status:** Accepted 2026-11-04.

Fictional power and engine capability are independent. Engine upgrades expand what can be modeled, not what every character automatically possesses. Existing histories and checkpoints must remain reproducible under pinned rule versions. Unsupported abilities are blocked pending a validated abstract-resolution mechanism.

See [power ceiling design](../architecture/versioned-power-ceilings.md).
