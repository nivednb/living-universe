# Intellectual property and release policy

Living Universe distinguishes original software, documentation, research outputs,
world data, and third-party sources. Publishing source code does not automatically
license unrelated datasets, art, trademarks, or unreleased results.

- **Engine code:** intended for Apache License 2.0, permitting commercial reuse
  subject to its conditions, including preservation of applicable notices. A
  canonical `LICENSE` file must be added before this policy is treated as a
  completed software-license grant.
- **Existing documentation:** governed by `LICENSE-DOCS` (CC BY 4.0), except
  where a file or third-party attribution says otherwise.
- **Original datasets, generated worlds, research outputs, artwork and fiction:**
  no blanket license is granted by this policy. Each public release should have
  its own explicit terms and provenance review. Public GitHub access alone does
  not authorize unrestricted reuse.
- **External sources:** retain source, author, URL, access date, original license,
  transformation notes and restrictions. Never claim ownership of external
  materials or unprotectable facts.
- **Research discoveries:** distinguish potentially copyrightable expressions,
  original selection/arrangement and code from ideas, facts and scientific
  methods. Evaluate patent, database-right and confidentiality questions before
  public disclosure of potentially valuable results.
- **Contributions:** document ownership and license provenance; changing licenses
  later may require contributor permissions. Earlier valid license grants remain
  effective for copies already received.
