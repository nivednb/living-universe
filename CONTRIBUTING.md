# Contributing

Living Universe is a personal creative hobby with an ambitious long-term design. Ideas, corrections, research, tests and code contributions are welcome.

Open an issue before large changes. Explain which documented world invariant is affected and why. Prefer small reviewable pull requests, deterministic tests and documented design decisions. Avoid introducing expensive always-on services or dependencies without a benchmark and rationale.

Only contribute material you have rights to license; identify third-party origins and obligations. Be respectful in discussions. Planned features should never be presented as implemented.
